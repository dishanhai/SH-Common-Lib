# JEI 搜索面板布局和构建

- 宽 AE2 终端在高 GUI 缩放下可能同时挤占容器右侧和底部的候选空间。候选区域不够时应退回搜索框左侧的浮层区域，保持搜索框和右侧素材网格可见。
- 状态：resolved（布局和索引实现）；游戏内验证待办见 TODO.md。
- 用户截图显示搜索框上方是 JEI 物品网格，直接向上放面板会被物品覆盖；应按容器边界和锚点选择左侧可用区域，并限制配方预览在同一区域。
- 大型素材集合的索引和匹配不能每次在绘制线程同步执行；采集 JEI 数据留在客户端线程，文本索引与匹配使用快照和后台任务，并丢弃过时查询结果。
- Java 字段不能用局部变量类型推断 `var`；后台执行器字段应声明 `ExecutorService`。Forge 构建首次因此失败，修正后重新构建。
- “框选的目标”是当前选中的候选行；主面板保留原玻璃样式。JEI 的 drawRecipe 使用 getRectWithBorder，配方背景可扩展到内容矩形外，应预留外边界并裁切，再绘制标题。
- 用户要求搜索框聚焦时由增强层独占无修饰键的上下箭头；滚轮在候选或搜索框上按行移动，跨过页边界时翻页，首尾继续滚动则循环。保留 Ctrl+上下历史与 Alt+左右翻页。
- NeoForge 26.1.2 模块目录没有独立的 `gradlew`；从项目根目录使用 `./neoforge-1.21.1/gradlew -p neoforge-26.1.2 ...`，并使用该模块所需的 Java 25 工具链。不要把找不到模块内脚本误判为编译失败。
- 用户反馈胶囊展开时 HUD 外观回退。动画帧不能先绘制一块浮层、再在裁剪区叠加完整 HUD；应让 UUK 在动画矩形绘制一次与静止状态相同的背景，再裁剪并绘制前景和选中行，开合及中断都使用同一条路径。
- JEI 的搜索组件关闭了 EditBox 边框，且自行将组件坐标移动到文字位置；灰色行内补全应使用该无边框输入的文字起点和基线，不能再次添加四像素内边距或垂直居中，否则会落到右下方。
- SHCLIB 根目录没有 `gradlew`；Forge 构建应使用 `./forge/gradlew -p forge`。从根目录直接运行 `./gradlew` 的尝试未执行构建，改用模块包装器后通过。
- 后续工作区已将 Forge 模块改名为 `forge-1.20.1`，当前主版本为 0.3.0；检查产物前应以当前构建配置和文件时间确认路径及版本，不能继续检查旧的 0.2.0 JAR。
- 与 JEIGuess 共存时两个候选面板和按键会重叠。JEIGuess 0.6.7 的 `suggest.enabled` 控制候选，但聊天链接另有开关；应让玩家明确选择并保存，使用其配置对象更新并保存总开关，而不是关闭整个模组或覆盖其他配置。保存失败时保持山海搜索关闭并允许重试。
- 用户明确要求预览不避让 JEI 历史与书签区域，直接叠层覆盖，并始终显示当前键盘选中素材的 tooltip；不要根据截图自行改成避让这些区域。
- 用户截图显示，选中项 tooltip 以候选面板右边缘为界时仍会盖住候选行。将换行、定位和绘制的边界设在候选面板左边缘之前，可同时避开候选行与右侧 JEI 素材网格。旧版通过 UUK 的有界 ingredient tooltip 接口保留原生素材渲染流程，26.1.2 使用受限宽度采集组件和有界定位器绘制。
- 标签翻译测试需严格匹配完整键名；用 `endsWith` 模拟片段翻译会错误地命中完整 `tag.item` 键，导致测试替身与真实资源查找语义不一致。
- NeoForge 26.1.2 的 `ServerPlayer` 不再公开 `getServer()`；热词服务端处理应从 `player.level().getServer()` 取得服务器，跨版本不能直接照搬旧端签名。
- NeoForge 26.1.2 的窗口句柄方法为 `Window.handle()`，旧版本使用 `getWindow()`；按键状态查询不能直接照搬旧版，须分别编译验证。
- 搜索配方预览的槽位 tooltip、JEI 原有 tooltip 与选中项 tooltip 会互相叠加；应按当前鼠标位置确定显示优先级，同时避免快速切换候选时反复同步创建配方。
- JEI 搜索框聚焦时，配方和用途键还会产生单独的字符输入事件；处理鼠标悬停素材的 JEI 快捷键时，应读取 JEI 当前键位，并限定同屏、按键仍按下及短时窗口来拦截对应字符。
- 2026-11-15：选中项 tooltip 仅避开候选列表仍会与其左侧配方预览重叠，且配方 z=400 时图标可能穿过 tooltip。已在配方可见时复用 UUK 有界 tooltip 接口，将右边界放到配方外框左侧，并在预览渲染上下文绘制；无预览时保持列表左侧边界，配方槽悬停继续优先。
- JEI 候选中的深色物品名会触发 UUK 的浅色自动描边。即使配方 tooltip 中的同一名称正常，候选仍可能出现抢眼白边。应在共享绘制策略控制浅色描边的强度，保留候选名称原有填充色。
- 有界 tooltip 的换行只处理文本，图形组件会报告自己的宽高。仅缩窄虚拟视口再开启裁剪会丢失内容；应在原生渲染拿到完整组件尺寸后，连边框留白一并适配视口，并在裁剪区域内统一缩放。
