# JEI 搜索面板布局和构建

- 状态：resolved（布局和索引实现）；游戏内验证待办见 TODO.md。
- 用户截图显示搜索框上方是 JEI 物品网格，直接向上放面板会被物品覆盖；应按容器边界和锚点选择左侧可用区域，并限制配方预览在同一区域。
- 大型素材集合的索引和匹配不能每次在绘制线程同步执行；采集 JEI 数据留在客户端线程，文本索引与匹配使用快照和后台任务，并丢弃过时查询结果。
- Java 字段不能用局部变量类型推断 `var`；后台执行器字段应声明 `ExecutorService`。Forge 构建首次因此失败，修正后重新构建。
- “框选的目标”是当前选中的候选行；主面板保留原玻璃样式。JEI 的 drawRecipe 使用 getRectWithBorder，配方背景可扩展到内容矩形外，应预留外边界并裁切，再绘制标题。
- 用户要求搜索框聚焦时由增强层独占无修饰键的上下箭头；滚轮在候选或搜索框上按行移动，跨过页边界时翻页，首尾继续滚动则循环。保留 Ctrl+上下历史与 Alt+左右翻页。
- NeoForge 26.1.2 模块目录没有独立的 `gradlew`；从项目根目录使用 `./neoforge-1.21.1/gradlew -p neoforge-26.1.2 ...`，并使用该模块所需的 Java 25 工具链。不要把找不到模块内脚本误判为编译失败。
- 用户反馈胶囊展开时 HUD 外观回退。动画帧不能先绘制一块浮层、再在裁剪区叠加完整 HUD；应让 UUK 在动画矩形绘制一次与静止状态相同的背景，再裁剪并绘制前景和选中行，开合及中断都使用同一条路径。
- JEI 的搜索组件关闭了 EditBox 边框，且自行将组件坐标移动到文字位置；灰色行内补全应使用该无边框输入的文字起点和基线，不能再次添加四像素内边距或垂直居中，否则会落到右下方。
- SHCLIB 根目录没有 `gradlew`；Forge 构建应使用 `./forge/gradlew -p forge`。从根目录直接运行 `./gradlew` 的尝试未执行构建，改用模块包装器后通过。
- 后续工作区已将 Forge 模块改名为 `forge-1.20.1`，当前主版本为 0.3.0；检查产物前应以当前构建配置和文件时间确认路径及版本，不能继续检查旧的 0.2.0 JAR。
