# 跨版本加速适配

- 状态：resolved
- 范围：百工·寰宇、ULK 加速、UUK 世界叠加
- Minecraft 26.1.2 将 `ResourceLocation` / `ResourceKey.location()` 改为 `Identifier` / `identifier()`，实体不再提供 `getServer()`；从 `ServerLevel` 取得服务器。将存储键、维度和天体环境查询隔离为小型版本替换类，避免复制整个调度器。
- 26.1.2 天体角度由环境属性提供，不能沿用 `ServerLevel.getTimeOfDay`。天气循环和原版云层也需分别核对实际版本源码，不将 1.21.1 的渲染时间字段直接套用到 26。
- AE2 的方块实体 ticker 与节点 `IGridTickable` 可以并存。线缆总线还需遍历部件工作节点，并按节点身份去重。
- 滑块拖动期间收到服务端快照时不要重建控件；保留本地预览，在提交时同步最终值。
- 带累计云层位移的同步消息必须携带维度，并面向该维度的观察者。不能把无维度的旧配置响应写入刚切换后的客户端维度。
- “加速期间关闭 AI”包含原版 tick。仅在额外 tick 前后暂改 NoAI 无法满足该语义；应合并多个目标请求，保存原状态，在最后请求结束时恢复，并通过实体持久标记处理卸载、重启和实例替换后的恢复。
- SHBUI 26 现有音乐源码的移植错误与纯 Java kernel API 可独立验证。兼容构建以明确的有效基线为输入，只添加已测试的 kernel 类，并核对其余归档内容；这不等于该版本的完整 UI 源码构建通过。
