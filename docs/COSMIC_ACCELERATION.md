# 百工·寰宇加速

主手持杖，按 **X** 打开加速配置，按 **G** 打开原有手杖配置。「时间加速」是两页共享的总开关，关闭会暂停该玩家的手杖加速并保留范围配置。普通模式的直接目标持续 600 个游戏 tick；永久模式保留目标，第三种模式还会关闭空闲降频。

## 操作

- Shift + 右键方块：额外执行机器 ticker、AE 节点或随机刻；对避雷针增加雷暴期间露天引来真实闪电的机会。
- Shift + 右键非玩家实体：额外执行实体完整 tick。AI 开关可在整个有效加速期间关闭 Mob AI，最后一个禁用 AI 的加速请求结束后恢复原有状态；暂停、到期和停服同样会释放该状态，实体重新加载时修复遗留恢复标记。
- 瞄准太阳或月亮，Shift + 右键：额外推进所在维度的昼夜及原版天气循环；遵守对应游戏规则，原版云层同步位移。
- Shift + 滚轮：按顺序选择关、x2、x4、x16、x32、x64、x128、x256、x512、x1024。
- 在范围页开启放置后右键选定中心。X/Y/Z 是各轴的总边长，各为 1～15 格；透明钟不占用方块，可以与机器同格。

## 范围与名单

每个范围独立保存倍率、模式、加速名单、休眠名单和运行缓存。加速黑名单排除标记机器，白名单只加速标记机器；休眠名单以相同规则独立控制哪些机器允许空闲降频。无法可靠识别空闲的机器保持正常加速。

两个名单按钮同时选择编辑目标，并显示当前范围的标记数量。编辑与放置互斥。编辑时右键切换一格，Ctrl + 右键切换本人已开启范围内的同类型机器，再次操作可取消。编辑期间暂停该玩家的加速并消费普通右键操作。画面持续显示当前黑／白名单，机器上显示对应文字。

历史记录包含放置时间、维度和坐标。选中记录可编辑该范围，远程启停保留配置；回收需再次确认，随后移除范围与时间流逝标记。范围记录保存在该存档的服务端，而非客户端配置中。永久范围可在收起手杖或玩家离线后继续工作；关闭总开关可统一暂停。

## 世界显示

持杖时显示附近正在加速的机器。全速边框流彩，空闲降频时为金色；时间流逝中心显示绿色框，范围显示边框与透明旋转钟。暂停的范围保留标记。实体头顶的进度条跟随目标移动，普通目标显示剩余时间，永久目标显示满条与无限标记。首次持杖及未打开配置前的首次直接加速、换挡各提示一次，每玩家每存档最多三次。

投影、裁剪、盒子与钟面几何由 SH-Better-UI 的 UUK `WorldOverlayGeometry` 提供。需要配套更新对应版本的 SHBUI；26.1.2 当前使用文档下述兼容构建。

## 执行预算与 API

全部玩家、范围与维度共享服务器执行预算：每 tick 最多 2048 次额外调用，调用调度按约 2ms 的截止时间停止；缓存扫描每 tick 全服最多检查 64 格，不强制加载区块。负载超出预算时欠账顺延，选择高倍率不保证服务器能实时完成该倍率。单次第三方调用开始后无法中途抢占；所有者、直接目标和范围元数据的准备遍历也无法抢占，因此 2ms 不是整个系统耗时的绝对上限。

其他模组可在服务器线程调用 `api.ulk.acceleration.TickAcceleration.submit(server, tick, count)`，向相同的预算队列提交工作。队列有上限，返回 false 表示未入队；回调工作不跨重启持久化。第三方回调失败时暂停相应工作并记录日志。

## 构建与验收

Forge 1.20.1 和 NeoForge 1.21.1 使用 Java 21，在各目录执行 `./gradlew build`。NeoForge 26.1.2 使用 Java 25。

SHBUI 26.1.2 的现有音乐界面源码仍有迁移错误。本次纯 Java UUK API 可由 SHBUI 的 `gradle/world-overlay-compat.init.gradle` 基于现有有效 26.1.2 模组 JAR 独立构建：测试几何契约、记录基线 SHA-256，并逐字节核对所有其余归档条目。详情见 SH-Better-UI 的 `docs/WORLD_OVERLAY_API.md`。SHCLIB 26 构建通过 `-PshBetterUiJar=<兼容包路径>` 使用此依赖；运行时也需要安装对应兼容包。

构建及纯逻辑测试不能替代游戏内交互、第三方机器和多人性能验收；实际客户端与联机待验项目记录在根 `TODO.md`。
