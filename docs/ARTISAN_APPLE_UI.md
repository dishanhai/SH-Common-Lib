# 百工配置与轮盘

短按 G 打开配置，长按 G 打开轮盘，松开快捷键收起轮盘；使用玩家已改绑的配置键时沿用同一手势。开关均读取实际手杖状态，发出请求后显示等待确认，超时提示重试。

配置采用 UUK 原生设置行开关，名称和说明在左，滑块在右。宽视口使用侧栏，窄视口使用分段导航。选项超出可见区域时，可在列表内使用滚轮或拖动右侧滚动条。使用键盘切换焦点时，列表跟随焦点滚动。切换分组时从顶部开始，重新打开配置时恢复上次的分组和滚动位置。编辑布局支持拖动预览与取消、Alt＋上／下移动焦点分组、撤销和保存失败提示。

轮盘的每页六个操作位围绕中央状态区。悬停或键盘焦点进入某项后，中央显示该项名称与确认状态；未选中时显示当前分组及开启数量。完整提示保留说明和状态。空间不足时使用两列紧凑布局；按钮均保留键盘焦点和原生激活方式。

所有原有模式、Boss 策略、空区瞬移默认关闭、信标入口与可选 AE 功能保留。辅助分组新增加速设置入口，可打开原有 X 配置。X 页面此次不改业务和布局。

实现位置：`CosmicArtisanMenu` 统一选项目录；公共与 26.1.2 的 `CosmicArtisanScreen` 负责业务和版本绘制适配。可复用的开关、手势和布局由 SHBUI/UUK 提供，不复制进 SHCLIB JAR。

安装时需同步更新对应 SHBUI；26.1.2 使用包含世界覆盖与设置行 API 的 `artisan-controls` 兼容包。构建与实际验收记录随本次交付保存，尚未实测的内容列入根目录 `TODO.md`。

本次验证：三端 SHCLIB 构建、SHBUI Forge／1.21.1 完整构建与测试、26.1.2 控件兼容包及布局契约均通过。实机客户端尝试期间发现共享依赖被另一轮构建重写，改用固定副本重试时用户停止电脑控制，尚未完成配置与轮盘的实际画面验收。日志位于 `build/reports/artisan-apple-ui`。
